# 当前视觉规格

当前参考：`codex-v2-concept.png`。内置 Image Gen 生成的完整主屏概念，原生尺寸 1536×1024。第一版深色概念 `concept.png` 保留为历史参考。

视觉系统：白色主区 `#ffffff`、浅灰侧栏 `#f6f6f5`、细边框 `#e7e7e5`、炭黑文字 `#242424`；桌面侧栏 292px，顶部栏 80px，输入框最大宽度 950px。主标题 40px，手机 27px。全部文字、控件和图标由 React/CSS/SVG 原生实现。

Image Gen 简述：完整个人远程 AI 编程工作台，接近 Codex 桌面端的浅色视觉与工作方式；包含项目和最近会话侧栏、新任务与搜索、顶部终端/代码修改入口、居中标题与输入区、项目/引擎选择和黑色圆形发送按钮，无营销区块或虚构指标。

实现中的必要差异：显示真实项目与会话，未加入概念图的示例记录；没有输入时发送按钮会变灰；资格受限时增加连接状态说明；真实任务才显示停止与原生会话详情。移动端为抽屉侧栏，终端/代码入口用可访问名称的图标按钮。

已经使用独立无头 Chrome 截图，并通过 view_image 对照检查：侧栏与主区布局、字体层级、白/浅灰/黑配色、输入区尺寸与留白、原生控件与图标、手机折叠与登录表单。输入区实测 x=439、宽 950、高 174，对应概念相同位置与比例。

修正过的差异：主标题由 36px 调整为 40px；手机初次切换视口的侧栏过渡闪现；favicon 404。概念中的静态示例内容与空输入发送按钮的状态差异属于有意的功能实现。

本轮验收使用本地服务 http://127.0.0.1:8765，视口 1536×1024、1024×768、390×844。Browser 插件不可用，采用独立临时配置的无头 Chrome；未读取现有浏览器资料。截图与临时 QA 脚本在源码目录外。外网 Access 登录后的浏览器流程和实体 Safari 尚未验收。
